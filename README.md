# Abhishek Borase Portfolio Website

A responsive React portfolio website created from your resume content.

## Files

- `index.html` — Vite entry HTML
- `package.json` — React + Vite project configuration
- `vite.config.js` — Vite settings
- `src/main.jsx` — app entrypoint
- `src/App.jsx` — React portfolio UI
- `src/index.css` — site styling
- `public/Abhishek_Borase_20260401.pdf` — downloadable resume

## Preview

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npm run dev
   ```
3. Open the local URL shown in the terminal.
